# 연구 기록

결정, 그 이유, 확인한 사실을 날짜순으로 남긴다. 실험 수치의 원본은 각 실험 폴더의 README에 있다.

## 2026-11-05

### 오늘 한 일

1. Fast-DetectGPT를 1B급 대표 모델(Llama-3.2-1B)로 재현했다. 평균 AUROC 0.793으로 논문(0.913)보다 낮았고, 같은 모델의 Likelihood(0.826)보다도 낮았다.
2. 코드부터 검증했다. 논문과 같은 GPT-Neo-2.7B로 돌리니 기준 방법 3개가 27칸 모두 논문과 0.001 이내로 같았다. 코드 문제가 아니다.
3. 원인을 분해했다. 샘플링 모델과 채점 모델이 같으면 분자는 토큰 수 × (Likelihood + Entropy)다. Llama는 GPT-3.5/4 글에서 entropy가 크게 떨어져 likelihood 상승을 상쇄한다.
4. 채점 모델 6개를 비교했다. 상쇄는 증류로 만든 최신 모델(Llama-3.2 1B/3B, Gemma-3-1B)에서 크고, GPT-Neo 1.3B/2.7B와 OLMo-2 1B에서는 작다.
5. 토큰 단위로 분석했다. When Less is More의 β로는 채점 모델이 구분되지 않는다. 대신 Llama에서는 저entropy 자리에서 AI 글 신호가 뒤집힌다.

자세한 수치: [experiments/01_fastdetectgpt_1b/README.md](../experiments/01_fastdetectgpt_1b/README.md)

### 결정과 이유

- **모든 모델을 실험하지 않는다.** 1B급 대표 모델 하나로 먼저 재현한다. 채점 모델을 늘린 건 재현이 실패한 뒤, 원인을 가르기 위해서다.
- **원인을 어디까지 팔 것인가.**
  - "Llama만의 문제인가, 최근 모델 전반의 문제인가"는 지금 확인한다. 앞으로 어떤 채점 모델로 실험할지가 여기서 갈린다.
  - "왜 그런가(증류냐 데이터냐)"를 확정하는 건 급하지 않다. 다만 진행하면서 가를 수 있는 비교는 쌓는다.
- **원인을 모르고 진행하면 생기는 위험.**
  1. 나중에 만든 방법의 효과가 채점 모델 하나의 결함을 메운 것일 수 있다.
  2. 같은 문제가 있는 채점 모델을 모르고 고를 수 있다.
  3. 원래 주제와 바로 연결된다. 설문 응답 탐지에서 실제로 잡아야 할 글은 ChatGPT류로 쓴 짧은 답변이고, 바로 Llama가 쉽다고 보는 문체다.

### 문제 정의 후보

> 최신 채점 모델에게는 채팅 모델 글이 평범한(typical) 글이 된다. 그래서 문맥 난이도로 정규화하는 zero-shot 탐지기(Fast-DetectGPT 등)는 신호를 잃는다. 같은 채점 모델의 단순 Likelihood는 멀쩡하다.

리뷰어에게 심각하다고 말하려면 아래 증거가 필요하다. 하나라도 실패하면 주장은 그만큼 작아진다.

1. 여러 채점 모델에서 재현한다. (진행 중: 6개 완료, 3개 대기)
2. 최신 생성 모델에서도 재현한다. 지금 데이터는 2023년 GPT-3.5/4가 뉴스 앞부분을 이어 쓴 글이다.
3. 다른 정규화 기반 탐지기(Binoculars)에서도 확인한다.
4. 짧은 설문 응답(ASURRE)에서 재현한다.
5. 통제 실험으로 메커니즘을 확인한다.
6. 선행연구와의 차이를 정리한다. (아래)

| DetectRouter (ICML 2026) | 채점 모델 불일치가 성능을 크게 좌우한다. KL로 점수 평균 차이의 상한을 준다. 방향(부호)은 말하지 않는다 | 불일치 문제 자체는 알려져 있다. 우리 쪽 새로움은 "더 최신 모델일수록 나빠지는 방향"과 그 메커니즘이다. 요약본으로만 본 두 항목은 미검증이다 |

### ChatGPT 검토에서 받아들인 것

- 정규화 항(σ)을 분자와 따로 본다. 확인 결과 정규화의 영향은 0.004 이하다.
- LoRA 통제 실험에는 같은 주제·길이의 사람 글로 같은 양을 학습시킨 대조군을 둔다.
- 같은 계열의 base와 instruct 모델을 쌍으로 비교한다.
- 테스트 AUROC를 보고 탐지기를 고르지 않는다.
- When Less is More의 β를 같이 잰다. 측정했고, 채점 모델이 구분되지 않았다.
- 4bit 대조 실험은 AUROC만이 아니라 토큰별 L·E와 β까지 비교한다.

GPT가 새로 제안한 상쇄 비율 C = −ΔH/ΔL은 우리가 쓰는 "남은 비율"을 뒤집은 값이다(C = 1 − 남은 비율).

### 증류냐 데이터냐: 지금까지의 판단

- 상쇄가 큰 모델(Llama-3.2, Gemma-3)은 모두 증류로 만들었고, 2023년 이후 데이터로 학습했다.
- 상쇄가 작은 모델(Neo, OLMo-2)은 증류를 하지 않았고, 대부분 ChatGPT 이전 데이터로 학습했다. OLMo-2의 주 데이터인 DCLM은 2023년 이전 Common Crawl이다.
- 따라서 두 가설은 아직 섞여 있다. 가르기 위한 실험은 다음과 같다.
  - **SmolLM2-1.7B:** 증류 보고는 없고, 2024년까지의 웹과 LLM 합성 데이터로 학습했다.
  - **Llama-3.1-8B (4bit):** 증류 교사 모델이다. 같은 Meta 데이터에서 증류만 빠진다.
  - **Llama-3.2-1B 4bit 대조:** 양자화가 결과를 바꾸지 않는지 먼저 확인한다.

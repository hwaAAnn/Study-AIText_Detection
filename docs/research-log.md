## 2026-11-06

### SmolLM2: 증류 없이도 상쇄가 생긴다

- SmolLM2-1.7B는 원논문 기준으로 증류 없이 처음부터 학습했다. 논문에서 "distillation"은 비교 대상인 Llama-3.2를 설명할 때만 나온다.
- 그런데도 상쇄가 Llama 수준이다.
  - 남은 비율 39%
  - GPT-3.5/4 6세트 모두 FDG < Likelihood
  - 저entropy 자리 신호 역전(약함)
- 판단:
  - "증류가 원인"이라는 가설은 유일한 원인으로는 약해졌다.
  - "학습 중 LLM 산출물에 노출"이라는 더 넓은 가설과 맞는다. 노출 경로는 세 가지다.
    - 증류: 큰 모델의 분포를 직접 배운다.
    - 2023년 이후 웹과 LLM 합성 교재
    - LLM이 평가해서 고른 데이터(FineWeb-Edu는 Llama-3-70B의 평가로 골랐다)
  - 증류가 효과를 더할 여지는 남아 있다. xsum_gpt-4 남은 비율이 Llama 14%, SmolLM2 49%다.

### 4bit 양자화 대조: 8B를 4bit로 돌리지 않는다

- GPT 검토의 제안대로 Llama-3.2-1B를 fp16과 4bit로 같은 조건에서 비교했다. 토큰별 L·E, β, FDG, AUROC를 비교했다.
- β는 거의 유지됐다(두 집단 모두 약 −0.025). 하지만 4bit 모델은 entropy가 전체적으로 오르고, AI 글에서 더 많이 오른다.
- 그 결과 xsum_gpt-4 FDG가 0.594에서 0.736으로 바뀌었다. 우리가 재려는 성질 자체를 양자화가 바꾼다.
- 결정: 4bit 결과는 비교에 쓰지 않는다. 8B는 디코더 층을 하나씩 GPU에 올리는 정확한 fp16 방식으로 돌린다(`--layerwise`). 이 방식은 Llama-3.2-1B 20쌍에서 일반 fp16 결과와 차이 0으로 확인했다.

### Llama-3.1-8B: 증류하지 않은 교사 모델도 무너진다

- Llama-3.1-8B는 Llama-3.2를 증류할 때 쓴 교사 모델이고, 자기 자신은 증류 없이 학습했다. 층별 fp16 방식으로 9세트 전체를 돌렸다.
- 상쇄는 Llama-3.2와 같거나 조금 더 크다.
  - 남은 비율 29%
  - GPT-3.5/4 6세트 모두 FDG < Likelihood
  - 저entropy 자리 신호 역전(+0.061 대 −0.010)
- 판단:
  - Llama 계열의 상쇄는 증류 과정에서 생긴 게 아니다. 그 위의 Meta 학습 데이터나 학습법에서 온다. Llama-3.2는 교사에게서 물려받았다.
  - 크기를 8B로 키워도 사라지지 않는다.
  - 그러니 처음 세운 증류 가설은 원인이 아닌 쪽으로 정리된다. 남는 설명은 2023년 이후 학습 데이터(LLM 글 포함), 합성 데이터, LLM 기준 데이터 필터링 같은 데이터 쪽 경로다.

### 선행연구 2차 재검토 (본문 전체)

질문은 "채점 모델이 학습 중 LLM 산출물에 노출되면 정규화 기반 탐지기가 무너진다"를 이미 주장하거나 시험한 연구가 있는지였다. 그런 논문은 찾지 못했다. 가까운 것은 다음과 같다.

| 논문 | 겹치는 부분 | 우리가 새로 하는 부분 |
|---|---|---|
| IRM (arXiv 2604.21223) | DetectRL에서 Llama-3.2-1B(-Instruct)로 채점한 FDG가 60~66, 같은 모델 Likelihood가 83~97이다. "FDG만 예외"라고 적었을 뿐 원인 설명은 없다 | 원인, 어떤 채점 모델에서 생기는지, 인과 검증. 이 표는 독립 재현 증거로 인용한다 |
| RoFT (arXiv 2311.08349) | GPT-3.5 글로 학습한 Phi-1.5가 GPT-3.5 글의 perplexity 탐지를 더 잘한다 | 노출이 likelihood는 돕지만 정규화된 점수는 망친다는 쪽 |
| DivScore (arXiv 2506.06705) | LLM 출력으로 미세조정한 채점 모델은 LLM 글에서 entropy가 낮다(장점으로 사용). 실패 원인은 전문 분야에 익숙하지 않은 것이다 | 모델 세대와 학습 노출이라는 축 |
| Detecting the Machine (arXiv 2603.17522) | GPT-2/Neo와 생성 모델의 코퍼스가 겹친다고 주장만 한다. 옛 채점 모델만 쓴다 | 최신 채점 모델 비교 전체 |

결정: 피봇하지 않는다. 기여는 관찰 자체가 아니라 다음 세 가지로 잡는다.
1. 원인: 학습 노출 때문에 AI 글이 채점 모델에게 평범해지고, entropy가 likelihood와 함께 움직여 상쇄된다.
2. 인과 검증.
3. 짧은 채팅체 설문 응답에서 생기는 결과.

원고를 쓰기 전에 최근 논문을 다시 확인한다.

### 학습 데이터의 LLM 글 비율을 실증할 수 있나

- Llama와 Gemma는 데이터가 비공개라 직접 잴 수 없다. 데이터 기준 시점과 웹 AI 글 비율 추정치로 간접 추정만 할 수 있다.
  - 웹 AI 글 비율 추정치는 arXiv 2610.36631(71개 Common Crawl 스냅샷)을 쓴다. 2022년 말까지는 낮고, 2023년 2월~2025년 1월에 해마다 +4.6%p 늘었다.
- 할 수 있는 방법은 세 가지다. 뒤로 갈수록 증거가 강하다.
  1. **공개 코퍼스의 AI 글 비율 측정:** Pile, DCLM, FineWeb-Edu, Cosmopedia 표본을 탐지기로 재고, 2022년 이전 데이터로 오탐지율을 보정한다. 기술적 근거다.
     - 주의: SmolLM2의 합성 교재는 전체 토큰의 약 0.3%(마지막 단계 4%)인데도 효과가 컸다. 비율보다 학습 단계(마지막 단계)가 중요할 수 있다.
  2. **TiC-LM 체크포인트로 자연 실험:** 같은 학습법으로 Common Crawl을 특정 시점까지만 써서 학습한 Apple 모델(1B/3B)이다. 2021년, 2023년 1월, 2024년 7월 마감 모델을 비교하면 데이터 시기만 다르다. OpenLM 형식이라 변환이 필요하고, 이용 조건을 확인해야 한다.
  3. **노출 비율 조절 추가 학습:** GPT-Neo-1.3B에 LLM 글 0~50%를 섞어 같은 양만큼 추가 학습하고, 사람 글 대조군과 비교한다. 인과 증거다.
- 추천 순서는 2 → 3 → 1이다.

### TiC-LM 자연 실험: 2024-07 컷오프에서만 무너진다 ([실험 02](../experiments/02_tic_lm_data_era/README.md))

- 쓴 모델: Apple TiC-LM Oracle 1B 7개(컷오프 2013-05 ~ 2024-07). 구조, 토크나이저, 필터, 학습량이 같고 Common Crawl 컷오프만 다르다.
  - DCLM의 fastText 품질 분류기는 GPT-4 생성 예시로 학습됐다. 논문은 인과성 문제로 이 분류기를 빼고 학습했다. 그래서 "AI 글 같은 텍스트를 고르는 필터" 효과도 섞이지 않는다.
  - 이용 조건은 비상업적 연구 목적만 허용이다.
- 결과보다 먼저 판정 기준을 실험 README에 적어두고 돌렸다.
- 결과:
  - 2013~2023-01 컷오프 6개는 keep 67~69%다. 인접 컷오프 차이는 ±1.6%p 안이다. GPT-Neo·OLMo처럼 FDG가 Likelihood보다 높다.
  - 2024-07 하나만 keep 38%, GPT-3.5/4 6세트 모두 FDG < Likelihood다. 2023-01 대비 −28.7%p, 쌍 bootstrap 95% CI [−30.8, −26.9]이다.
  - davinci 글과 사람 글에 대한 점수와 entropy는 2023-01과 2024-07이 거의 같다. 변화는 채팅 모델 글에서만 생긴다.
  - 토큰 단위로 보면 AI 글 토큰 31%의 entropy가 0.5 nat 넘게 떨어졌다. 대조 구간(2021→2023)은 6.6%, 사람 글은 7.9%다. 특정 표현이 아니라 기능어 전반이 떨어졌다. 채팅 모델 문체를 하나의 익숙한 분포로 배운 것으로 보인다.
  - 같은 모델에서 Likelihood 탐지는 오히려 좋아졌다(0.918 → 0.949). 노출은 likelihood 차이를 키우지만, entropy 차이가 그보다 더 커져서 정규화 점수를 망친다.
- 판단:
  - 실험 01의 남은 설명이던 "2023년 이후 학습 데이터"가 다른 조건을 고정하고 재현됐다. 연구의 핵심 주장을 받칠 첫 인과적 증거다. 시기를 직접 조작한 자연 실험이라 상관관계 비교보다 강하다.
  - 노출량은 추정상 학습 데이터의 1% 미만이다. 2023~2024 덤프는 약 10%, 그 안의 AI 글은 몇 %다. 작은 양으로도 큰 효과가 난다는 점이 설문 응답 탐지에 주는 함의가 크다. 앞으로 나올 채점 모델은 모두 이 웹으로 학습되기 때문이다.
- 남은 질문과 다음 실험 후보(비용 낮은 순):
  1. **2024-07 이후 공개된 채팅 모델의 글**(예: Qwen2.5-Instruct, 2024-09 공개)로 같은 XSum 앞부분을 이어 쓰게 하고 다시 잰다. 2024-07 모델이 본 적 없는 모델의 글에서도 무너지면 "채팅 문체 일반"이다.
  2. **사람 글의 시기 대조:** 2022년과 2024년의 사람 뉴스(BBC 월별 기사 등)로 같은 비교를 한다. 2024 사람 글에서도 entropy가 크게 떨어지면 AI 글이 아니라 웹 시기 변화 쪽이다.
  3. **3B Oracle로 반복:** 2023-01과 2024-07 두 개만 받는다(각 11GB). 층별 실행이 필요하다.
  4. **AI 글 주입 추가 학습:** 2023-01 모델에 ChatGPT 글과 사람 글을 비율별로 섞어 추가 학습한다. "AI 글 자체"가 원인인지 직접 보는 인과 실험이다. 6GB GPU에서는 LoRA나 더 작은 모델이 필요하다.

## 2026-11-05

### 오늘 한 일

1. Fast-DetectGPT를 1B급 대표 모델(Llama-3.2-1B)로 재현했다. 평균 AUROC 0.793으로 논문(0.913)보다 낮았고, 같은 모델의 Likelihood(0.826)보다도 낮았다.
2. 코드부터 검증했다. 논문과 같은 GPT-Neo-2.7B로 돌리니 기준 방법 3개가 27칸 모두 논문과 0.001 이내로 같았다. 코드 문제가 아니다.
3. 원인을 분해했다. 샘플링 모델과 채점 모델이 같으면 분자는 토큰 수 × (Likelihood + Entropy)다. Llama는 GPT-3.5/4 글에서 entropy가 크게 떨어져 likelihood 상승을 상쇄한다.
4. 채점 모델 6개를 비교했다. 상쇄는 증류로 만든 최신 모델(Llama-3.2 1B/3B, Gemma-3-1B)에서 크고, GPT-Neo 1.3B/2.7B와 OLMo-2 1B에서는 작다.
5. 토큰 단위로 분석했다. When Less is More의 β로는 채점 모델이 구분되지 않는다. 대신 Llama에서는 저entropy 자리에서 AI 글 신호가 뒤집힌다.

자세한 수치: [experiments/01_fastdetectgpt_1b/README.md](../experiments/01_fastdetectgpt_1b/README.md)

### 결정과 이유

- **모든 모델을 실험하지 않는다.** 1B급 대표 모델 하나로 먼저 재현한다. 채점 모델을 늘린 건 재현이 실패한 뒤, 원인을 가르기 위해서다.
- **원인을 어디까지 팔 것인가.**
  - "Llama만의 문제인가, 최근 모델 전반의 문제인가"는 지금 확인한다. 앞으로 어떤 채점 모델로 실험할지가 여기서 갈린다.
  - "왜 그런가(증류냐 데이터냐)"를 확정하는 건 급하지 않다. 다만 진행하면서 가를 수 있는 비교는 쌓는다.
- **원인을 모르고 진행하면 생기는 위험.**
  1. 나중에 만든 방법의 효과가 채점 모델 하나의 결함을 메운 것일 수 있다.
  2. 같은 문제가 있는 채점 모델을 모르고 고를 수 있다.
  3. 원래 주제와 바로 연결된다. 설문 응답 탐지에서 실제로 잡아야 할 글은 ChatGPT류로 쓴 짧은 답변이고, 바로 Llama가 쉽다고 보는 문체다.

### 문제 정의 후보

> 최신 채점 모델에게는 채팅 모델 글이 평범한(typical) 글이 된다. 그래서 문맥 난이도로 정규화하는 zero-shot 탐지기(Fast-DetectGPT 등)는 신호를 잃는다. 같은 채점 모델의 단순 Likelihood는 멀쩡하다.

리뷰어에게 심각하다고 말하려면 아래 증거가 필요하다. 하나라도 실패하면 주장은 그만큼 작아진다.

1. 여러 채점 모델에서 재현한다. (진행 중: 6개 완료, 3개 대기)
2. 최신 생성 모델에서도 재현한다. 지금 데이터는 2023년 GPT-3.5/4가 뉴스 앞부분을 이어 쓴 글이다.
3. 다른 정규화 기반 탐지기(Binoculars)에서도 확인한다.
4. 짧은 설문 응답(ASURRE)에서 재현한다.
5. 통제 실험으로 메커니즘을 확인한다.
6. 선행연구와의 차이를 정리한다. (아래)

### ChatGPT 검토에서 받아들인 것

- 정규화 항(σ)을 분자와 따로 본다. 확인 결과 정규화의 영향은 0.004 이하다.
- LoRA 통제 실험에는 같은 주제·길이의 사람 글로 같은 양을 학습시킨 대조군을 둔다.
- 같은 계열의 base와 instruct 모델을 쌍으로 비교한다.
- 테스트 AUROC를 보고 탐지기를 고르지 않는다.
- When Less is More의 β를 같이 잰다. 측정했고, 채점 모델이 구분되지 않았다.
- 4bit 대조 실험은 AUROC만이 아니라 토큰별 L·E와 β까지 비교한다.

GPT가 새로 제안한 상쇄 비율 C = −ΔH/ΔL은 우리가 쓰는 "남은 비율"을 뒤집은 값이다(C = 1 − 남은 비율).

### 증류냐 데이터냐: 지금까지의 판단

- 상쇄가 큰 모델(Llama-3.2, Gemma-3)은 모두 증류로 만들었고, 2023년 이후 데이터로 학습했다.
- 상쇄가 작은 모델(Neo, OLMo-2)은 증류를 하지 않았고, 대부분 ChatGPT 이전 데이터로 학습했다. OLMo-2의 주 데이터인 DCLM은 2023년 이전 Common Crawl이다.
- 따라서 두 가설은 아직 섞여 있다. 가르기 위한 실험은 다음과 같다.
  - **SmolLM2-1.7B:** 증류 보고는 없고, 2024년까지의 웹과 LLM 합성 데이터로 학습했다.
  - **Llama-3.1-8B (4bit):** 증류 교사 모델이다. 같은 Meta 데이터에서 증류만 빠진다.
  - **Llama-3.2-1B 4bit 대조:** 양자화가 결과를 바꾸지 않는지 먼저 확인한다.
